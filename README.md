# pixel-whale · 像素小鲸鱼

## 中文

DeepSeek Harness 侧边栏的**像素小鲸鱼桌宠**。打开面板就是一只手绘像素鲸鱼（13×8 精灵，canvas 逐像素渲染）在水族箱里生活：

- 🐋 **自主巡游**：左右游动、上下浮动、随机换向，还会**眨眼**
- 🫧 **吐泡泡**：气孔定时冒像素泡泡，摇摇晃晃升到水面
- 🍤 **投食**：点击水面扔一粒食物，小鲸鱼会**游过去吃掉**，吃下冒像素爱心
- 🤚 **摸摸**：点鲸鱼本体，它开心地摇摆 + 冒一串爱心
- 纯前端、零网络、零配置，`requestAnimationFrame` 驱动，DPR 适配高分屏

<a id="english"></a>
## English

A **pixel-art whale pet** for the DeepSeek Harness sidebar. The panel is a small aquarium: a hand-drawn 13×8 pixel whale (rendered per-pixel on canvas) swims around, bobs, blinks, and blows pixel bubbles. **Click the water** to drop food — the whale swims over and eats it (pixel hearts!). **Click the whale** to pet it (wiggle + hearts). Pure client-side, zero network, zero config, DPR-aware.

## Install / 安装

- **Plugin Market**（收录后）: Plugins → Plugin Market, search `pixel whale`
- **CLI**: `dsh plugin --profile <profile> add https://github.com/Wldeinsamkeit/pixel-whale`
- **Manual**: clone and run `install_bundle` pointing at this directory
